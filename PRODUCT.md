# GestureGuard HMI

<!-- impeccable:product-schema 1 -->

## Platform
web, served locally by a Python application.

## Stack
User-requested Python 3.11, MediaPipe, OpenCV, NumPy, FastAPI, SQLite; React, TypeScript, Vite, Tailwind and Motion.

## Users
Two Diploma Computer Science students presenting their FYP to university examiners; operators participating in a later controlled evaluation.

## Product Purpose
Demonstrate and evaluate intentional touchless commands for three simulated industrial workstations. Explain detection, pending intent, authorization, rejection and execution clearly.

## Positioning
The original contribution is a testable interaction architecture: temporal filtering, explicit unlock, contextual permission checks, preview, separate confirmation, release gating and auditable evaluation. Pretrained gesture recognition is a dependency, not an original model claim.

## Operating Context
Laptop webcam, local-only software, projector demonstration. Camera failure must leave a complete clearly labeled simulated-input demonstration available.

## Capabilities and Constraints
No cloud services, accounts, real industrial control, certified emergency stop, fake measured benchmarks or calibrated confidence probabilities. Start locked and with all stations stopped. Live, replay and injected inputs must always be distinguishable. Keyboard and manual controls supplement gestures.

## Brand commitments
Premium precision-engineering control center, charcoal surfaces, restrained teal, clear status colors, professional typography and purposeful motion. User authorized autonomous implementation and design decisions; no further routine design approval needed.
