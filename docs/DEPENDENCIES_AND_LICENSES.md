# Dependency and source notes

The application is original integration code built around maintained open-source libraries. No whole third-party application was cloned. API usage follows official documentation; record exact installed versions in the committed lockfiles generated by setup. Model weights are a separately downloaded dependency, not original trained work.

| Dependency | Use | Upstream license / documentation |

Review packaged transitive notices before redistributing an installer. This document identifies upstream projects and does not replace their notices. The runtime requires no cloud AI subscription or account. Initial package/model installation requires internet access; installed operation is local.

The downloader uses the official MediaPipe model artifact at `https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task` (float16, version 1). It records the actual downloaded file's SHA-256 and byte length in `models/model-manifest.json`. The large `.task` artifact is excluded from Git. Preserve the manifest with the reproducibility package and confirm it before comparing study sessions.

## Documentation verification

Context7 documentation was used for MediaPipe Tasks, FastAPI lifecycle/WebSocket, Vite/Tailwind integration, and pytest. The official MediaPipe setup documentation supports the selected Python 3.11 environment. Actual platform/package compatibility is established by installation, imports, model initialization, tests, and a separate real-webcam acceptance test; a successful install does not prove camera performance.
