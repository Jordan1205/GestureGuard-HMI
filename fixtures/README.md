# Input provenance

`demo-replay.json` and `comparison-stream.json` contain prepared scripted observations. They are not recorded human webcam sessions and must not be used as recognition-accuracy evidence. The interface labels their playback as Recorded Replay / scripted input; no live camera classification occurs during replay.

`comparison-stream.json` is generated by `gestureguard.evaluation.scripted_fixture()` and declares expected scripted intention for deterministic architecture evaluation. `run_comparison()` uses that same generator, records commands from fresh isolated engines, labels them against the declared intention, and reports hashes. The static JSON is useful for inspection and replay; the generator is authoritative if the fixture changes.

To collect real observation replay data, select Live Camera and export the current session through `/api/replay/export`. Preserve session conditions, settings, software/model hashes, and source labels. Replaying those inference outputs evaluates downstream interaction behavior; it does not recompute image recognition. Separately consented video fixtures would be needed to evaluate the recognizer itself on identical images.
